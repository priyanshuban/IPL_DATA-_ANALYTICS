# IPL Data Analytics Project — Statistical Findings

## Dataset
- Matches: 1,095
- Delivery records: 260,920
- Seasons: 17
- Source: Kaggle IPL match and ball-by-ball datasets supplied for this project.

## Key Findings
1. **Toss → Match Outcome:** The toss winner also won the match in **50.83%** of completed matches.
2. **95% confidence interval:** Approx. **47.86% to 53.79%** for the observed toss-to-match-win proportion.
3. **Top run scorer in the dataset:** V Kohli with 8,014 runs.
4. **Top wicket taker using bowler-credited dismissals:** YS Chahal with 205 wickets.

## Statistical Interpretation
The toss-win percentage is close to one-half, so the descriptive result alone should not be interpreted as proof that winning the toss causes winning the match. A stronger analysis could use a two-proportion test by toss decision, season, venue, and match type.

## Recommended Dashboard KPIs
- Matches played
- Total runs
- Total wickets
- Win percentage by team
- Toss decision split
- Toss-to-match-win percentage
- Top 10 run scorers
- Top 10 wicket takers
- Season-wise matches
- Venue-wise match count
